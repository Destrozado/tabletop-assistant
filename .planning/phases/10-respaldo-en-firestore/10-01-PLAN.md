## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| navegador → Firestore (`firestore.googleapis.com`) | La primera llamada de red saliente del cliente en producción de este proyecto. Todo lo que cruza aquí es, por definición, no confiable para el servidor. |
| `GameHistoryEntry` local → documento de Firestore | Frontera de proyección: lo que no cruza esta frontera nunca sale del dispositivo. |
| bundle público (repo público) → configuración de Firebase | La configuración web viaja en el build y cualquiera puede leerla. No es un secreto; la barrera real son las reglas. |

ASVS L1, bloqueo en `high`.
