<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sesión reanudada ↔ pantalla | `playerSlots` es lo primero que convierte un `context` restaurado de `localStorage` en algo que se pinta; una forma inesperada no puede llegar a la plantilla |
| datos autorados ↔ render | Que un paso pinte o no la rejilla lo decide una clave del dato; ningún componente ni composable puede decidirlo comparando contra un id |
| motor ↔ Vue | `useGameSession.ts` es la única costura; si un componente necesitara algo del motor, falta una computed aquí |
