## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → vistas de pantalla | Las entradas leídas pueden estar manipuladas; sus cadenas acaban interpoladas en el DOM |
| Catálogo (generado desde API de terceros) → nombres congelados | Un `heroId` puede quedar huérfano al regenerar el catálogo |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

El nombre ya viene recortado a `PLAYER_NAME_MAX_LENGTH` por `resolvePlayerSlots` |
| T-09-16 | Tampering | `heroId` huérfano tras regenerar el catálogo | mitigate | D-11: el nombre se congela al registrar; si falta, se pinta el nombre guardado y, en su ausencia, el propio id — nunca un hueco ni un fallo |
| T-09-17 | Information disclosure | Un composable que dejara «preparada» una segunda fuente de datos | mitigate | `reload()` solo llama a `loadHistory()`; sin parámetros de fuente, sin ramas de red, sin `async`. Gate de grep en los criterios de aceptación |
